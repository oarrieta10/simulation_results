Simulation Results

Check a simulation against the design it was sized for, in two steps. You can also drop both kinds of file here at once.

  1. 1

    Design inputs

    The design inputs JSON exported from the Customer Success Tool: workstation types, flows, demand and workstation counts per scenario (Average, Peak …). It sets the targets each run is checked against.

  2. 2

    Simulation reports

    One or more DP Simulation Report HTML exports (or extracted .json). Load Average and Peak to compare them.

Everything runs locally in your browser. Nothing is uploaded. Imported design inputs are remembered in this browser only.
